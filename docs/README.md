## What the R numbers mean

- **R1** - File upload validation and rejection of bad files.
- **R2** - Historical data retention and record integrity.
- **R3** - KPI endpoint coverage and KPI value correctness.
- **R4** - PDF report generation and report content completeness.
- **R5** - Upload permissions by role (viewer/analyst/admin).
- **R6** - Dashboard filter response and error-free completion.
- **R7** - Protected routes and successful login sessions.
- **R8** - Profile completion redirect and profile update success.
- **R9** - Verification gate before access and post-approval access.
- **R10** - Admin user management actions and admin-only permissions.
